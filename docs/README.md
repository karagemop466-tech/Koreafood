# GitHub Pages site

Static viewer for **388 verified restaurants and 94 verified cafes** in this repo. This pass added 20 new restaurant/cafe records from official Visit Seoul and Visit Busan pages; existing records were retained and cafes remain separate. Restaurants and cafes are kept in separate tables/data files; use the city filters and search for Myeong-dong, Gangnam, Hongdae, Dongdaemun, or Busan areas.

- Data is generated from the city markdown tables (`cities/*.md`).
- Only official source URLs already in those tables are linked.
